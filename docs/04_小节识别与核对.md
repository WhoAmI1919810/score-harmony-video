# 04 小节识别与核对

小节划分是后面所有东西的地基：对齐、阴影、和弦都挂在小节上。**这一步错一个小节，之后所有编号都会错位**，用户校对时会非常痛苦。所以这一步的验收标准是逐页对上印刷的小节号，而不是"看起来差不多"。

## 方法（`s2_bars.py`）

1. **去斜。** 先估计谱线的倾斜和竖线的倾斜，做剪切变换，结果存到 `中间文件/pages_deskew/`。
2. **找五线组。** 候选峰取三种：最强峰、质心、原始峰。只用一种会漏谱表：扫描弯曲的页上，峰会被拆开。
3. **分系统。** 系统之间有空隙，或者谱表之间有花括号、方括号的连线。
4. **找小节线。** 找贯穿谱表的竖线。之后 `refine_system` 去掉系统开头的窄条和页末的预告记号，并补上虚线小节线（钢琴声乐谱常见）。
5. **应用 `数据/小节修正.txt`。**
6. **出核对图。** `中间文件/bars_debug/pNNN.png`，每个小节画框、标号。

总谱用 `s2_bars_fullscore.py`：页图先放大 `upscale` 倍（总谱谱线间距常只有 9～10 像素），再去斜，然后用同一套方法。结果先写成分段文件，再由 `fs_fix.py` 合并、套用 `总谱小节修正.txt`。

## 验收：逐页对上印刷的小节号

1. **读页角的小节号。** `fs_corner_numbers.py 起页 止页` 把每页左上角拼成一张图，人工读出来，写进 `数据/总谱页首小节.txt`。缩谱一般印的是排练号，同样可以拿来用。
2. **对数。** `fs_check.py`（或 `fs_fix.py`，它最后会自动调用）逐区间比较"识别出的小节数"和"印刷编号差"，列出不符的页。
3. 对每个不符的页，打开 `bars_debug/pNNN.png`（太大就用 `fs_sheet.py 页`，或者自己裁剪放大），**看清楚**是哪种错误，写进修正文件，重跑。
4. 直到"不符的区间 0"、总数 = `total_bars`，才算过。

注意：**页角印号本身也会印错。** 马勒八总谱第 145 页印的是 850，实际是 849。判断方法：数前一页实际有几个小节，再和后面一页的印刷号交叉核对。

## 常见错误（按出现频率）

| 错误 | 样子 | 修法 |
|---|---|---|
| 系统开头的谱号、调号窄条被当成一个小节 | 每行第一个"小节"特别窄（宽度不到中位数的四成） | `去线 页 y 窄条右边的x`。按"最窄小节 ÷ 中位宽"排序，一次就能找出一批 |
| 页末的预告调号被当成一个小节 | 每行最后一个"小节"特别窄 | 同上 |
| 第一、二小节之间的小节线漏了 | 某页少 1 个小节 | `fs_missing.py 页` 按竖线墨迹找候选 x，再 `加线` |
| 调号变化处的小节线漏了 | 同上 | 同上 |
| 符干被当成小节线 | 多出 1 个小节，常在长音符干对齐的地方 | `去线` |
| 一个系统被谱表之间的空隙断成两个 | 上下两个"系统"的小节线位置完全一样 | `fs_fix.py` 自动合并：x 差在 12 像素内就合 |
| 两个系统被并成一个 | 系统中间有系统分隔记号 `//` | `find_merged.py` 用模板找 `//`，然后改 `staves.json` 拆开，再重读这一页 |
| 谱表漏了 | 这页小节框只覆盖了上半部分 | 候选峰的问题，回去看 `find_staves`，或者把这页单独重跑 |

## 经验

- **按宽度排序找窄小节**最有效：马勒八总谱一次就找出了 15 个多出来的小节。
- 总谱识别慢（216 页，单进程约 40 分钟）。可以把页范围分两段，用两个进程跑：`python3 s2_bars_fullscore.py 1 108` 和 `… 109 216`，结果分别写到 `部分识别_*.csv`，由 `fs_fix.py` 合并。
- 识别有错时，不要直接改 `小节位置.csv`，要写修正文件，否则下次重跑就丢了。
- 用户在校对站上合并、拆分小节后，导入时会自动把修正写回（`import_checker.py`）。

## 换一份总谱时：用排练号对编号

新换的谱没有印小节号，或者印号和原来那份不同时，用排练号方框核对：
1. `rehearsal.py 页图目录 小节位置.csv 输出.csv`：两份谱各跑一次。它找空心方框，再把方框归到小节上。
2. `compare_rehearsal.py 已核对的.csv 新的.csv`：比较排练号归到的小节号。
3. 看结果：
   - 绝大多数差 0，说明编号一致；
   - 连续一段差同一个数，是那一段开头多了或少了小节；
   - 只差一两个、前后又回到 0 的，多半是方框落在小节线附近、归错了小节，不用改。

马勒八换 Muzgiz 版时：自动识别得到 2152 小节，总数正好对上。但排练号查出两处一多一少，互相抵消了：一处系统开头的窄条被当成小节，一处漏了小节线。**总数对上不等于逐段对上。**
