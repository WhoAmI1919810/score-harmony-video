# 09 踩坑记录（真实项目里发生过的，按环节排）

每条都写了：现象 → 原因 → 现在的做法。新 agent 遇到类似情况，先来这里查。

## 小节

1. **用户说的小节号对不上。**
   - 原因：用户报的是他当时网页上的编号，之后补过 6 个小节、删过 1 个，我凭记忆减了 1。
   - 做法：一律按谱面位置换算（`renumber.py`、页加坐标）。
2. **总谱识别多了 32 个小节。**
   - 原因：系统开头的窄条 15 处，页末的预告调号 3 处，被谱表空隙断开的系统 1 处（多出 22 个）。
   - 做法：按宽度排序找窄小节；`fs_fix.py` 自动合并小节线一致的上下系统。
3. **少了 8 个小节。**
   - 原因：第一、二小节之间的小节线漏了。
   - 做法：`fs_missing.py`。
4. **页角印号本身印错**（145 页印的 850，实际是 849）。
   - 做法：和前后页的数量交叉核对。
5. **缩谱里两个系统被并成一个。**
   - 原因：两个系统的小节线恰好对齐。
   - 做法：`find_merged.py` 找系统分隔记号 `//`。
6. **符干被当成小节线**：缩谱 II-874/875 原来是一个小节，是对着总谱的排练号查出来的。

## 对齐与校对

7. **整段偏几十秒到两分钟。**
   - 原因：第一遍假设均速。
   - 做法：`align_dtw.py`，自由 DTW，只信已校的固定点。
8. **假锚点。**
   - 原因：校对站拖动时自动标"已确认"，用户腾空间时挤出一串假确认点。
   - 做法：固定点只认 `已校范围.txt`。
9. **用户改错位的小节时没地方挪。**
   - 原因：网页只有整体缩放。
   - 做法：改成后面的小节整体平移，再加自动重排、合并、拆分、补删、拖阴影边框。
10. **发布网页失败。** 原因有两个：体积超过 50 MiB；HTML 里有被托管拦截的 `url(` 字样。
    - 做法：压缩谱页和音频；用 `URL["createObjectURL"]`。

## 和声

11. **自动和声低级错误多**，用户不接受。
    - 做法：改成人工逐小节读，`和弦_人工.txt` 盖掉自动结果。
12. **C#m 变成了 C。**
    - 原因：解析时把 `#` 当成了注释。
    - 做法：注释的 `#` 只认行首，或者前后有空格。
13. **自动说明把句中的 V–I、转位的 I 写成终止式。**
    - 做法：自动说明只写转调，终止式人工写。
14. **"人工读完"其实照抄了候选**，最后 5 小节音没变却写了五个和弦。
    - 做法：读谱图不带候选；对总谱；`audit_chords.py`；汇报分清楚读的是哪份谱。详见 docs/06。
15. **自洽校验给了假安心**：`check_chords` 0 处不一致，可是和弦是错的。
    - 做法：汇报时说清楚每个校验查的是什么。
16. **等音拼写**（`Fx`、`B#`）：校验工具要能认，`note_pc` 支持 `x`。

## 文字与画面

17. **画面上出现 "II-390"**：说明里写了内部编号。做法：写"第 390 小节"。
18. **段落标题太长，挤掉了右边的小节范围。** 做法：自动缩小字号。
19. **标题、署名写死在代码里，换作品就得改代码。** 做法：全部挪到 `project.json`。

## 流程与运维

20. **全片渲完才发现时间轴和分析都要改**，66 分钟白跑。做法：用户还在改时只出预览。
21. **`pkill -f 某脚本` 把自己的 shell 也杀了**（命令行里含有同样的字样）。
    - 做法：先 `ps -eo pid,args | grep "[s]5_render"` 查出 PID，再按 PID 停。
22. **会话因为切换账号被中断。**
    - 做法：先看文件的修改时间和日志，确认哪些已经做完；不要重复写入、发布、提交，只继续没做完的部分。
23. **临时文件放在会话的 scratchpad 里，重启后就清空了。**
    - 做法：可复用的东西放工作目录，核对图放 `中间文件/核对图/`。

## 2026-11-12 起新增

24. **漏了大量还原号。**
    - 原因：读谱程序几乎不认还原号，我又参考了程序认出的音名。
    - 做法：不看程序的音名，以总谱为准，见 docs/06 第三次失败。
25. **小节总数对上，中间却一多一少。**
    - 做法：用排练号逐段比对，见 docs/04。
26. **扫描总谱太糊，叠在一起的和弦音读不出。**
    - 做法：去 IMSLP 找更清楚的版本。`fs_full.py` 直接从 PDF 原图截，不经过缩小的页图。
27. **用户在睡觉、没法标注。**
    - 做法：看不清的地方记进 `数据/待复核.txt`，自己先往下核对；用户回来后重新生成标音网页，一次给全。
28. **缩谱把"持续音 + 旋律 + 低音动机"排成了和弦的样子**，我按低音动机逐拍标了 VII7、Fø7、VI。
    - 做法：总谱上没有和弦乐器换音，就不换和弦，见 docs/06 的补充。
