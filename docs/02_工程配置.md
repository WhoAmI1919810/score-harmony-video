# 02 工程配置 project.json

每部作品一个工程目录，参数全在 `project.json`。脚本里**不写**任何作品专用的东西（页码、小节数、文件名、标题、调）。

- 起点：`project_template/project.json`，每个字段旁边都有 `_字段名` 形式的注释。
- 真实例子：`examples/mahler8/project.json`。
- 路径写相对工程目录的路径。

## 字段

| 字段 | 含义 | 怎么定 |
|---|---|---|
| `short_name` | 简称，用于文件名、校对站标题 | 随意，比如 `马勒8` |
| `home_key` | 主调：大写大调、小写小调，`Eb`、`f#` | 看谱 |
| `beats_per_bar` | 名义拍数 | 拍号多变的作品统一写 4（拍位按 4 个等分位置写） |
| `pickup_bar` | 弱起小节号 | 没有就 `null` |
| `total_bars` | 全曲小节数 | 读完乐谱最后一页印的小节号后填，核对小节识别用 |
| `display_score` | 画面左边显示哪份谱：`vocal` 是读谱用的那份，`full` 是总谱 | 用户要总谱就用 `full`（马勒八最后用的是总谱） |
| `reading_score.pdf / first_page / last_page` | 读谱用的谱子（钢琴或人声缩谱），以及正文的 PDF 页范围 | 跳过封面、目录；`first_page` 是第一小节所在的 PDF 页 |
| `reading_score.credit` | 片头署名 | 出版社、版号、来源 |
| `full_score.*` | 总谱（可选） | `upscale`：谱线间距小于约 12 像素时设 2，否则 1 |
| `audio.source` | 录音文件 | |
| `audio.trim` | `[起, 止]`，原文件秒数；`null` = 整个文件 | 整部交响曲的录音只取一个乐章时用 |
| `audio.cuts` | `[[a, b], …]`，原文件秒数，剪掉的空白 | 两部分之间 16 秒静音剪成约 4 秒：`[[1393, 1405]]` |
| `audio.end` | 剪辑后的总长 | `s3_audio.py` 跑完会打印 |
| `audio.music_start / music_end` | 第一个音、末和弦结束（剪辑后秒数） | 听出来 |
| `audio.part2_start` | 第二部分第一个音 | 单乐章填 `null` |
| `video.tail` | 末和弦后留几秒（淡出） | 5 |
| `text.*` | 画面文字：`title`、`title_card`、`subtitle`、`performer`、`output_name`、`part_names` | |
| `omr.*` | 谱号、升降号模板在本谱页面上的位置（像素） | **换谱子必须重量**，见下 |
| `fonts_dir` | 字体目录（含 `source_han/`、`freefont/`） | 工程目录或工具包下有 `字体/` 时不用填 |

## 两部分 / 单乐章

- **两部分**的作品（比如马勒八）：
  - `数据/两部分.txt` 写 `PART2_BAR = 第二部分第一小节的连续编号`、`LAST_BAR = 全曲小节数`；
  - 文件里一律用连续编号，画面上显示"第二部分 第 n 小节"，核对图上写 `II-n`。
- **单乐章**：不建 `两部分.txt`，画面上显示"第 n 小节"。
- **多于两部分**：目前不支持，要扩展 `textdoc.part_bar`。

## `omr.*`：读谱模板的位置

谱号和升降号的字形每个版本都不一样，所以模板要从本谱上截：

1. `build.sh pages bars` 之后，打开 `中间文件/pages_deskew/p001.png`（或者任何一页谱号清楚的），量出谱号左边缘的大致 x 坐标，填 `clef_x0`。
2. 找出那一页第几行谱表是高音谱号、第几行是低音谱号（从 0 数），填 `clef_staves`。
3. 找一处调号里有 2～3 个降号的地方，量每个降号的外框 `(x, y, 宽, 高)`，填 `flat_boxes`。升号同样，填 `sharp_boxes`。
4. 删掉 `中间文件/omr/templates8.npz`，重新读谱。

## 设备相关的参数不写在这里

进程数、降优先级、ffmpeg 线程数都用环境变量（`SV_JOBS`、`SV_NICE`、`SV_FF_THREADS`），见 `docs/10`。
