# 08 渲染与交付

## 预览（每次改完都要做）

```bash
python3 scorevid/s5_render.py --preview 30.5 600 1500 --png-dir 输出/预览
```
- 秒数是剪辑后音频的时间。要看某个小节，就到 `数据/小节时间.csv` 里查它的开始时间。
- **每张图都自己打开看**，重点看：
  - 阴影是否框在当前小节上；
  - 标题有没有出界；
  - 说明里有没有内部编号；
  - 和弦和谱上的音是否一致。
- 用户批评过的问题都是"图出了没看"：屋檐浮空、窗花贴错之类（在别的项目里）。

## 成片

- 服务器渲染：
  ```bash
  python3 scorevid/s5_render.py --jobs 2
  ```
  - 全片分成"进程数 × 3"段并行，渲完用 ffmpeg 拼接，再配音频（开头留静音，末和弦后淡出）。
  - 渲染开始时会给文字稿和时间表各拍一份快照，渲染过程中改文字不影响这一次。
  - 参考耗时：马勒八 80 分钟 1080p，8 核无显卡服务器上 2 个进程用了 66 分钟，文件 534 MB。
- **渲染之前确认时间轴和分析都是最终版**，这是我们的教训：
  - 第一版全片刚渲完，用户就交了新的时间轴；
  - 同时又指出了和声问题；
  - 66 分钟白跑。
  - 用户还在改的时候，先只出预览帧或一小段：`--start 秒 --end 秒`。

## 本地渲染包（服务器弱、用户自己渲染时）

`build.sh pack` → `输出/<简称>_本地渲染包.zip`，里面有：
- 脚本、`project.json`、文字稿；
- 小节位置和时间、显示用的谱页、FLAC 音频、字体。

用户在 Windows 上双击 `渲染.bat`（第一次会自动装依赖，ffmpeg 用 imageio-ffmpeg 自带的那个）。

## 网页交付

- 用户要看网页（校对站、说明页）时，**直接发布成临时网站，给链接和准确的过期时间**，不要发压缩包（用户明确要求过两次）。
- 修改已发布的页面时更新原链接，不要每次换新链接。
