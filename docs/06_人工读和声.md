# 06 人工读和声（最重要，也最容易偷懒）

视频的价值在于和声分析是对的。自动和弦候选（`harm_auto.py`）只是草稿，读谱音名有误读，按误读的音算出来的和弦更离谱。**我们的经验是：只要照抄过候选，用户一定能看出来。**

## 真实的失败

- **马勒八第一部分，第一版。** 用的是自动和声。用户说"现在还有很多低级错误"，于是第一部分改成人工逐小节读。
- **马勒八第二部分，第一版。** 号称"人工读完 1572 小节"，实际情况是：
  - 后半段几乎没打开总谱；
  - 一整页缩谱扫一眼就写，挤了 38 个小节的页也不放大；
  - 多半照抄了读谱图顶上的候选和弦；
  - 用"级数和和弦名 0 处不一致"当作质量证明。
- **用户随手指出最后 5 小节**：音一个没变，却写成了 I–iii–I–IV–I。实际情况是全体延长同一个 E♭ 大三和弦，铜管在上面奏旋律。
- 用户的原话："明明读过总谱，上一版为什么会出现低级错误"。之后第二部分只能整体重读。

## 读法

1. **读谱图不带候选和弦。** 用 `reread_sheets.py 起页 止页 --names`：只印小节号和淡色的读谱音名，不印任何和弦。
   - `read_sheets`（带候选）这类图不要拿来读，候选会把你带偏。
2. **一张图最多一两个系统。** 小节挤的页用 `vs_zoom.py 起小节 止小节` 放大。看不清音就再放大，不要猜。
3. **对总谱核对。** `fs_zoom.py 起小节 止小节 y0比例 y1比例 倍数` 把总谱的一段、一个声部区域放大，上方印着现在写的和弦，可以直接对照。
   - 缩谱是缩写，内声部和持续音常常省略或改写。
   - 拿不准的段落、持续音、半音化段落，一定要对总谱。
4. **先认低音，再认和弦。**
   - 持续低音上方的和弦照上方写，在说明里交代持续音。
   - 低音不是根音时写 `X/Y`。
5. **换不换和弦，看音变没变。**
   - 和弦音没变就不换和弦。旋律在主和弦上走动，不算换和弦。
   - 经过音、辅助音、倚音不单独标和弦。
6. **有调号、写得出功能，才标级数。**
   - 单线、空五度、半音化经过、没有调中心的地方写 `—`。宁可空着，不要编。
   - 整段调中心不明确时写 `调 —`。
7. **调号变了就写 `调 X`。** 同主音大小调交替时，借用和弦写 `♭VI`、`♭III`、`iv`，不要改调。
8. **转位**：文件里可以按实际写，比如 `I64`；画面上只保留 I、IV、V 的四六和弦。

## 验收（每读完一段就做）

1. `check_chords.py`：级数和和弦名必须 0 处不一致。**这只查自洽**，查不出"写了谱上没有的和弦"。
2. `audit_chords.py 起 止`：拿和弦和读谱音逐段比对，标出两类可疑：
   - A 类：换了和弦，可新出现的音都在前一个和弦里（"音没变却换和弦"）；
   - B 类：和弦音在谱上出现不到一半，或者谱上大半的音不在和弦里。

   读谱音有误读，所以只能当线索，可疑处要逐个回谱面看。
3. 出几帧预览，看画面上的和弦走带有没有一小节里乱跳的情况。
4. **汇报时**分开说清楚：哪些段落对照了总谱，哪些只看了缩谱，哪些写了 `—`、为什么。

## 效率

- 每页先看低音线和持续音，大段的持续音会让和弦变化变少，读得更快。
- 自己写的结果和旧版逐小节比一下（写个小脚本打印差异），差异处再看一眼谱面。这是第二道检查。
- 多部分的大型作品分段读，每段读完立刻写进文件。不要攒着，对话上下文可能被压缩。

## 第三次失败：还原号（2026-11-12）

- 用户在标音网页上标完 II-1~113 后指出："你漏掉了大量的还原号"。
- 拿用户标的音和读谱程序认的音逐个对：用户标了 51 个带 ♮ 的音，程序只认对 3 个。**读谱程序基本不认还原号**，凡是读谱图上印的淡色音名，在有还原号的地方几乎都是错的。
- 我重读时仍然瞄了那些音名，于是把 A♮ 读成 A♭、C♮ 读成 C♭。只要还原号一错，大三小三、属和弦和副属就全错，比如 II-28~36 其实转向 f 小调，我一直没看出来。

做法：
1. **不看读谱程序的音名**：`reread_sheets.py` 不加 `--names`。
2. **每个临时记号自己看**，记住同一小节里，同一个音位上的临时记号会延续到小节结束。
3. **以总谱为准**，缩谱只当索引。扫描总谱分辨率不够时，找更清楚的版本：IMSLP 上同一作品常有好几种扫描。马勒八换成 Muzgiz 版之后，还原号清楚可辨。
4. **看总谱的顺序**：
   - 先看低音提琴、大提琴，定低音；
   - 再看弦乐和合唱，这两组写的都是实际音高；
   - 最后看木管、铜管。圆号（F 调）、单簧管（B 调）是移调乐器：圆号写的音比实际高纯五度，单簧管写的音比实际高大二度。
5. **工具**：
   - `fs_view.py`：整个系统，上方印现在写的和弦，方便对照；
   - `fs_full.py`：从 PDF 原图截局部，最清楚；
   - `vs_crop.py`：缩谱局部，带音高标尺。
6. **看不清就交给用户标**（标音网页，见 `web/README.md`）：每条写清楚看哪个声部、哪个记号。用户睡觉或忙时先跳过，记进待复核清单，不要猜着写。

## 补充（2026-11-13，核对马勒八 II-167~170 时发现）

- **缩谱会把单线和持续音"写成"和弦。** 钢琴缩谱为了好弹，常把延长的高音、旋律和低音动机排在一起，看上去像一串和弦。对着总谱看，原来只是持续音加两条线。这种地方**按总谱写 i（或持续音上的那个和弦）延续，不要按低音动机逐拍编和弦**。
- **合唱段落例外**：缩谱里的合唱声部是原样照抄的，合唱和弦可以按缩谱读，总谱只用来核低音和乐队里的临时记号。


## 马勒八二次复核与标音回收

先确认谱号、调号、移调和跨小节延音，再写拍位与实音。遇到半音层叠，可记录低音、主要配音及经过音，和弦命名存疑时保留“—”。缩谱和总谱上的标音要以谱表、声部及音符位置对应，不能仅按音名或小节号套用。

全谱复核完成后，再按剩余疑点生成标音网页。每条问题写到小节、拍位、乐器和符头位置。回收时保留原始导出，将已确认的音高写回复核稿，随后重新生成文字稿和渲染包。ZIP 完整性检查和文字稿比对用于核对交付内容，谱面实音仍须靠读谱确认。
