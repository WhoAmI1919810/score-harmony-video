# 07 分析文字与画面风格

下面是我们这位用户明确提出、并在两个项目里反复确认过的偏好。换了用户，先按这个默认来做，有新要求再改。

## 内容

- **只讲和声思路**：和弦进行、终止、持续音、转调、大小调交替、离调、半音化。
  - 不讲配器、歌词、生平、标题意象。
  - 引用歌词只作段落标签，比如段落标题 "Waldung, sie schwankt heran"。
- **标 T / S / D 功能。** 副属和弦标 DD 或 (D)。这由 `textdoc.chord_function` 自动生成。
- **转位只保留 I、IV、V 的四六和弦**（终止四六、持续音上的四六），其他转位都不显示。
- **相同和弦合并**：连续几个小节同一个和弦，只显示一个。
- **终止式要人工判断。** 自动判断会把句中的 V–I、转位的 I 都当成终止。所以自动说明只写"转入 X 调"，终止式在 `[说明]` 里人工写。

## 文字

- 平实的陈述句，不比喻，不抒情。
  - 对："第 1558 小节低音转到 A♭（{IVmaj7}、{ii7}）。"
  - 不对："和声仿佛升入天际。"
- 级数写在花括号里：`{V7/V}`。画面会把它排成上标、斜线等格式。
- **引用小节写"第 n 小节"**（两部分的作品写本部分的编号），**不要写 `II-390`**。说明会原样显示在画面上，内部编号用户看不懂。
- 一条说明一两句话。说明多的段落，宁可分成几条。
- 段落导语交代：速度标记、拍号、调号、哪些声部进入。

## 画面

- 极简：深色背景，左边是谱，右边是和弦走带和说明，右下角是全曲曲式与调性进度条。
- 用户要求用总谱时，左边显示总谱（`display_score: full`）。
- 段落标题太长时会自动缩小字号，不能挤掉右边的小节范围。
- 只讲和声的片段可以加缩谱（`reduction.py` 用 verovio 排版），不需要的话就不加。
- 两部分之间的长静音剪成几秒（`audio.cuts`）。
- 1080p；不主动出 4K（我们的服务器太弱，见 docs/10）。
