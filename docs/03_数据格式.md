# 03 数据格式（`数据/` 下的文件）

标【人工】的是人工成果，脚本只读不写（`import_checker.py` 例外，它会按新编号改写，改之前先自动备份）。

## 小节

### `小节位置.csv`（读谱用的谱子）、`总谱小节位置.csv`（总谱）
```
bar,page,system,x0,x1,y0,y1
1,1,1,581,1037,670,3206
```
- `bar`：全曲连续编号。`page`：PDF 页。`system`：页内第几个系统（从 1 数）。
- 坐标是去斜后页图（`中间文件/pages_deskew/`，总谱为 `中间文件/总谱_deskew/`）上的像素。总谱是放大 `upscale` 倍后的坐标。

### 【人工】`小节修正.txt`、`总谱小节修正.txt`
```
去线 88 550 1458     # 说明
加线 15 2600 935
```
- `去线 页 y x`：把这一页上 y 所在系统里离 x 最近的那条小节线去掉（两个小节合并）。
- `加线 页 y x`：在这里补一条小节线。
- 按谱面位置写，**重新识别之后仍然有效**。不要直接改 csv。

### 【人工】`总谱页首小节.txt`
```
1 1
73 II-1
145 II-849   # 页角印 850，实为 849
```
- 每行是"PDF 页、这一页第一个小节的印刷编号"，从页角读。用来逐页核对小节数（`fs_check.py`）。
- 印刷编号也可能印错，要和前后页的数量交叉核对。

### 【人工】`两部分.txt`
```
PART2_BAR = 581
LAST_BAR = 2152
```

## 时间

### `小节时间.csv`（用户校对后是【人工】）
```
小节,开始,备注[,页,x0,x1,y0,y1,部分,原小节]
1,0:00:00.00,已确认
```
- 开始时间按剪辑后的音频计。
- 校对站导出的版本带谱面坐标，能表达合并、拆分、补小节；导入用 `import_checker.py`。

### 【人工】`已校范围.txt`
```
I-1 ~ I-580        # 11-07 交回
II-1460 ~ 末尾
```
对齐重排时，这些范围里的小节时间不动。**只写用户明确说过校对好的范围。**

### `对齐锚点.csv`、`中间文件/align/beats.csv`
- 锚点是导入时记下的确认点。
- `beats.csv` 是每小节 4 个名义拍的时间，渲染时在小节内部插值用。

## 和声与文字

### 【人工】`和弦_人工.txt`：权威的调与和弦
```
调 Eb
I-12 | 1 V7 Bb7 | 3 I Eb      小节 | 拍位 级数 和弦名 | …
I-13 | =                      和弦同上一小节
I-14 | 1 —                    没有完整和弦（单线、空五度、半音化经过）
调 —                          调中心不明确
```
- **拍位**按每小节 4 个等分位置写：1 是开头，3 是一半，可以写小数。6/4 拍的第 4 拍 = 3，第 5 拍 = 3.67。
- **级数**的写法：
  - 小调里的 III、VI、VII 按自然小调；
  - 借用和弦写 `♭VI`、`♭III`、`♭VII`；
  - 副属写 `V7/V`、`vii°7/ii`；
  - 增六写 `Ger6`、`Fr6`、`It6`，那不勒斯写 `N`。
- **和弦名**：根音 + 性质，可以是 `m`、`7`、`m7`、`maj7`、`°`、`°7`、`ø7`、`+`。低音不是根音时写 `Eb/G`。重升写 `Fx`。
- **注释**：`#` 必须在行首，或者前后都有空格。`C#m` 里的 `#` 是升号。我们踩过这个坑：C#m 被截成了 C。
- 用 `check_chords.py` 校验级数和和弦名是否一致（只查自洽，不查对错）。

### 【人工】`分析_人工.txt`
```
[曲式] 1-134 | I 呈示部                       右下角进度条的大段
[段落] 1-45 | 标题 | E♭ 大调                  下一行起是导语
导语……
[说明] I-46 | 说明文字，级数写在花括号里 {V7/V}
```
- 调性概括写成"E♭ 大调""e♭ 小调"这种格式时，会作为该段开头的调；写"调性游移"时不改调。

