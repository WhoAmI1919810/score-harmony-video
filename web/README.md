# 时间轴校对站（网页模板）

`校对站模板.html` 是单文件网页：读一组静态数据，让用户边听录音、边看谱面，校对每个小节的开始时间，还能直接修小节划分。马勒八项目的 2152 个小节就是用户在这个页面上校完的。

它不需要后端，任何静态托管都行，本机可以用 `python3 -m http.server`。

## 怎么生成、怎么发布

```bash
cd <作品工程目录>
bash <工具包>/build.sh site        # = make_checker.py（素材）+ make_site.py（拷模板、写对齐数据）
# 结果在 中间文件/校对站/，把整个目录发布成静态网站
```
- `make_checker.py` 第一次运行时生成谱页、音频、音高谱。之后谱页和录音没变时加 `--data-only`，只重写 `data.json`（`build.sh site` 会自动判断）。
- 发布新版本时更新原链接，用户的链接不变。
- 模板里的 `{{作品名}}` 由 `make_site.py` 替换成 `project.json` 的 `short_name`。

## 目录里的文件（数据约定）

| 文件 | 内容 |
|---|---|
| `index.html` | 模板 |
| `data.json` | 下面几项 |
| `pNNN.png` | 谱页，宽 1000 像素，量化成 4 级灰度（控制体积） |
| `spec/sNNN.png` | 录音的音高谱，每张 60 秒、每秒 20 像素，时间轴背景用 |
| `audio.mp3` | 录音，单声道（40～64 kbps） |
| `feats.bin` | 每 0.2 秒一帧：84 维音高谱 + 12 维色度，uint8 |
| `tpl.bin` | 每小节 4 个名义拍：84 维读谱音高模板 + 12 维色度模板，uint8，顺序同 `bars` |
| `align.json` | `{"fr":0.2,"frames":…,"dimP":84,"dimC":12,"beatsPerBar":4,"bars":…,"wPitch":0.7}` |

`data.json` 的字段：
- `bars[]`：`{n 编号, p 页, x0 x1 y0 y1 谱面框（已按页宽缩放）, t 开始秒, ch 和弦, key 调, lab 显示用的 "II-3", part, c 是否已确认}`；
- `sections[]`：`{a, b, title}`；
- `env`、`envFps`：响度包络；
- `spec`：`{sec, pps, tiles, lo, hi, rowPx}`；
- `pageWidth`、`pageHeight`、`scale`、`firstPage`、`lastPage`、`part2Bar`、`part1End`、`audioStart`、`musicStart`、`musicEnd`。

`feats.bin` 和 `tpl.bin` 用来在浏览器里重排小节，代价和 `align_dtw.py` 一样：0.7 × 音高谱余弦距离 + 0.3 × 色度距离。没有这两个文件时，页面仍能手工校对，只是不会自动重排。

## 页面功能（每一项都是真实使用中用户要求加的）

- 左边谱面阴影跟着播放走；下面是带音高谱的时间轴，竖线是小节起点。
- **拖一条小节线时，后面的小节整体平移**（不是缩放）。确认或拖动后，两侧没确认的小节会按录音自动重排。
- 改小节结构：
  - 合并 M、拆分 X、补小节 N、删除（Delete 按两次）；
  - 拖阴影边框，改小节在谱面上的范围。
- 快捷键：

  | 键 | 作用 |
  |---|---|
  | 空格 | 播放、暂停 |
  | ← → | 选小节 |
  | P | 从所选小节播放 |
  | T | 播放中在强拍上按，最近的小节线移到这里 |
  | S | 设为当前位置 |
  | [ ] | ±0.05 秒 |
  | C | 确认 |
  | R | 还原 |
  | Z | 撤销 |
  | A | 重排这一段 |
  | Esc | 取消 |
  | 滚轮、− + | 缩放时间轴 |

- **不会自动保存**：托管页面不能用 localStorage 和 cookie。用户要隔一阵"导出 CSV"，下次用"导入 CSV"接着改。页面上有提示，告诉用户时也要说清楚。

## 导出的 CSV

```
小节,开始,备注,页,x0,x1,y0,y1,部分,原小节
```
- 带谱面坐标，所以能表达合并、拆分、补、删。
- 交回后用 `import_checker.py 交回的.csv` 导入，见 `docs/05`。
- **"备注"里的"已确认"不能全信**：拖动过的小节也会被标成已确认。固定点以用户口头说的已校范围为准（`数据/已校范围.txt`）。

## 托管限制（我们用的托管，换托管时逐条检查）

| 限制 | 对策 |
|---|---|
| 单站 50 MiB | 谱页 4 级灰度、宽 1000 像素；音频 40 kbps 单声道 |
| 不支持 HTTP Range | 音频整段 fetch 成 blob 再播放 |
| HTML 里不能出现 `url(` 这类字样（被拦截） | 用 `URL["createObjectURL"]` 的写法 |
| 有效期最长 48 小时 | 发布时告诉用户准确的过期时间；过期要重新发布（新链接） |

# 标音网页（`标音模板.html`）

**用途**：读和声时，有些音实在看不清（还原号、重降号、叠在一起的和弦音）。把这些地方做成网页，让用户在谱面上点出位置、填音名，或者每小节写一句。

**生成**：
```bash
# 1. 在 数据/待复核.txt 写问题，每行：起小节~止小节 | 具体问题（写清楚看哪个声部、哪个记号）
python3 scorevid/make_doubt_site.py      # → 中间文件/校对音站/（index.html、data.json、img/）
# 2. 把 中间文件/校对音站/ 发布成静态网站；问题有增减就重新生成、更新原链接
```

**页面**：
- 左边是条目列表，用颜色标出处理进度。
- 每条有：具体问题、"我现在的读法"表（每小节一行，用户可以直接写）、缩谱和总谱截图（黄框是要看的小节，可缩放）。
- 可选显示读谱程序认出的音名，仅供参考：它几乎不认还原号。
- 在谱上点一下就出现输入框，填音名（有 ♭ ♮ ♯ 𝄫 𝄪 按钮）；点已有的标记可以改或删。
- 点"我的读法没问题"，这一条就算处理完。

**结果**：
- 不能自动保存，要提醒用户隔一阵导出一次 `标音结果.json`，或者"复制结果"直接粘贴发来。
- `python3 scorevid/import_doubt.py 标音结果.json` 按条目打印用户的标注。每个标记都带谱面坐标（页、x、y），可以和谱上的符头对位。

**马勒八实例**：36 条，用户标到 II-113。他指出的"漏掉大量还原号"，正是从这次标音里看出来的。
